# Prompt Optimization-Based Video Generation Agent System

This is a Streamlit app that generates cinematic video prompts based on user input and allows the user to modify the prompt and view the differences between the original and edited versions. 
The app also simulates generating a video using the final prompt.

## Features
1. **Describe Your Video Idea**: Enter a concept for a video.
2. **Edit Prompt**: Edit the generated prompt.
3. **See Differences**: Compare the original and edited prompts to see what was changed.
4. **Generate Prompt**: AI generates a cinematic video prompt based on the description.
6. **Generate Video (Mock)**: Display a mock video based on the final prompt.

## Requirements

- Python 3.9+
- Dependencies listed in `requirements.txt`

- ## Installation

1. Clone the repository:

    ```bash
    git clone https://github.com/Rao-Sanaullah/Video_Generation_Agent.git
    cd Video_Generation_Agent
    ```

2. Create a virtual environment (optional but recommended):

    ```bash
    conda create -n ai_app python=3.10
    conda activate ap_app
    ```

3. Install the required dependencies:

    ```bash
    pip install -r requirements.txt
    ```
    
4. Finally, "Run the Streamlit app":

    ```bash
    streamlit run app.py
    ```
